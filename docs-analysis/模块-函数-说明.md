## 已确认事实

- 索引覆盖后端入口/路由/视图(代表)/鉴权/模型基类/任务/工具、前端 root store/provider/service/auth、共享包关键导出、live 核心模块，均有 `路径:行号` 证据。
- 后端无 service 层；前端 store 内嵌 service；live Controller/Extension/Hook 三层。

## 合理推断

- `@plane/hooks/useOutsideClickDetector` 的 `useEffect` 无依赖数组为潜在 bug（每渲染重绑）。
- `@plane/services` 的部分 service（module 等）缺构造器且 0 消费者，疑似 stub。

## Unknown 与待验证事项

- 未穷尽全部 ~395 路由处理器、~90 模型字段、~34 任务（声明于覆盖范围）；EE 填充的 `Base*Store`/`extendedRoutes` 内容不在本仓库。

## 批判性评估

- 索引暴露的重复：两套 base view、两套 permission、两套 APIService、两套 UI Button——符号层面即可见重复。

## 建设性改善建议

- [Recommendation] 为关键模块补统一 service 层与 API 文档（drf-spectacular 可生成，但当前默认关闭）。优先级：中；难度：中。
- [Recommendation] 修复 `useOutsideClickDetector` 依赖数组与 0 消费者的 stub service。优先级：低；难度：低。
